# mossy-mayhem

Mossy Mayhem - open moss and turf, running out further than you can walk. No fence, no corners.

The map with nothing to put your back to. Open in a way the other two are not.

Drop MP3s straight in here - see `../README.md` for the format and why music is MP3 on both
builds when the sound effects are not. More than one file is a playlist rather than a mistake.

Empty for now, and this file is what keeps the directory in git.
