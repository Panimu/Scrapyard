# title

The title screen and every menu behind it - chassis select, level select, the workshop, the Scrapopedia, the changelog.

This is the only track most players hear twice in a row, because it plays while they decide what to do. It should reward being left on and should not build to anything.

Drop MP3s straight in here - see `../README.md` for the format and why music is MP3 on both
builds when the sound effects are not. More than one file is a playlist rather than a mistake.

Empty for now, and this file is what keeps the directory in git.
